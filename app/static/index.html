Tanzil's Beginner Guide: Pushing to GitHub

Follow these exact step-by-step commands in your Antigravity terminal to initialize Git and push your completed module to https://github.com/tanzilhassan7/SpectraDef.

  1. Open Terminal in Antigravity.
  2. Initialize Git repository:
    git init
  3. Set your default branch to main:
    git branch -M main
  4. Add all project files to Git:
    git add .
  5. Commit your code with a clear message:
    git commit -m "Add Tanzil's Image Input and YOLO Baseline Detection Pipeline"
  6. Link your local project to GitHub:
    git remote add origin https://github.com/tanzilhassan7/SpectraDef.git
  7. Push your code to GitHub:
    git push -u origin main
